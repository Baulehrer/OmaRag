# OmaRag 0.9.0 — System Colors, Calmer Identity

This release completes the rename to **OmaRag — Oracle of Metis & Aletheia** and makes the
terminal workbench feel native on an Omarchy desktop while keeping Vanilla Haiku RAG untouched.

## Highlights

- The compact one-line header now uses an orange ORACLE wordmark and restrained geometric Metis
  and Aletheia companions. Both remain subtly animated without competing with the workspace.
- A fifteenth **Omarchy System** theme reads the active
  `~/.config/omarchy/current/theme/colors.toml` palette and follows changes automatically. A
  contrast-safe fallback keeps it usable outside Omarchy.
- The project, repository links, release title, native archive, AppImage and container identity are
  now consistently named OmaRag.
- The 0.8 answer receipts, conversation continuity, bounded answer cache, selectable sources,
  mathematical text cleanup and textbook table/image handling remain intact.
- The SOAP-inspired three-pane shell, compact hardware monitor, four-role model setup and archived
  pre-SOAP TUI remain available unchanged.

## Compatibility

- Existing libraries, workspaces, configuration, systemd units and the `oracle` launcher keep
  their established paths so upgrading does not split or re-index local data.
- The legacy `ORACLE_REPOSITORY` override remains accepted; new automation may use
  `OMARAG_REPOSITORY`.
- Vanilla Haiku RAG remains an unmodified dependency behind the public compatibility gate.
- Linux x86_64 remains the packaged target.

## Release files

The release publishes the OmaRag terminal AppImage, native Linux archive, Python daemon wheel,
zsync metadata, installer, SHA-256 manifest and a non-root CPU container.
