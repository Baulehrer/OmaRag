# OmaRag 0.5.0 (legacy)

The first public preview of the Offline Retrieval-Augmented Command-Line Environment.

Highlights:

- a colorful, mouse-aware terminal workbench for local PDF libraries;
- layout-aware Docling imports with page, heading, table and bounding-box provenance;
- clickable answers, source pages and up to four visual evidence previews;
- hardware-aware Chat, VL, Embedding and Rerank model recommendations;
- OOM-conscious segmented indexing with chat priority and configurable profiles;
- AppImage client, full CPU Docker image and one-command Linux installer;
- opt-in weekly auto-update timer and AppImageUpdate metadata.

This preview is local-first. The AppImage is the portable console client and connects to the
daemon installed by `install.sh` or served by the Docker image. Ollama models and libraries are
not bundled and remain under the user's control.
