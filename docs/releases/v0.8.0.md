# Oracle of Dædalus 0.8.0 — Answers with Receipts

This release makes repeated textbook work faster and follow-up questions easier to audit while
keeping Vanilla Haiku RAG unchanged.

## Highlights

- Chat now sends and preserves real conversation IDs across questions, restarts and restored
  history entries.
- Exact repeated questions can reuse a bounded SQLite answer cache. The key includes the active
  books, configuration, request, adapter and Oracle version; book and settings changes invalidate
  cached answers automatically.
- The Source inspector adds a compact, plain-language answer receipt: fresh or safely reused,
  question number, sources checked, known/new evidence and the result of the source check.
- Image questions bypass the answer cache so visual evidence is always evaluated for that request.
- The SOAP-inspired TUI expansion from 0.7 is completed: compact hardware and model status,
  fourteen themes, Markdown chat, selectable source pages and the simplified four-role model setup.
- The pre-SOAP terminal UI remains archived under `backups/tui-pre-soap`; Vanilla Haiku RAG remains
  an unmodified dependency behind the public compatibility gate.

## Compatibility

- Existing state databases migrate in place; older runs receive isolated legacy conversation IDs.
- Existing workspaces and Haiku vector databases do not need to be rebuilt.
- Linux x86_64 remains the packaged target.

## Release files

The release publishes the terminal AppImage, native Linux archive, Python daemon wheel, zsync
metadata, installer and SHA-256 manifest. The AppImage is the client; the installer or container
provides the local Python/Haiku backend.
