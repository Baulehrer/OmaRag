# OmaRag 0.7.0 (legacy) — Lean Local Intelligence

This release rebuilds Oracle around a compact SOAP-inspired terminal workbench and makes the
local RAG control plane substantially smaller at idle without changing Vanilla Haiku RAG.

## Highlights

- A clean three-pane TUI separates navigation, the active task and contextual detail with a
  compact header, clear borders, direct sub-navigation and reliable `Ctrl+C` shutdown.
- Chat, Library, Models and Settings keep their complete workflows while presenting fewer controls
  at once; fourteen themes, keyboard, mouse and colored shortcuts remain first-class.
- The hardware rail reports CPU, RAM, VRAM and all four configured/loaded model roles. Fast,
  Balanced and Quality presets install and activate atomically; custom IDs and GGUF stay available.
- Chat renders Markdown and moves figures, pages and citations into the Source inspector, where
  arrows or mouse clicks open the original PDF at the selected page.
- The long-lived API starts without importing Haiku, Docling, PyTorch or SentenceTransformers.
- Import and query work run in isolated, disposable workers with separate cgroup and watchdog
  budgets. Query workers leave after an idle timeout and release native model memory.
- Ollama models used by an expiring worker are unloaded at the same lifecycle boundary.
- The API control plane has its own 768 MiB no-swap ceiling, while import and query workloads get
  independent limits matched to their jobs.
- The installed runtime uses the slim Haiku dependency set and CPU-specific PyTorch packages.
- Long-book ingestion, structure-aware chunking, textbook metadata, evidence validation,
  retrieval evaluation and the public Haiku compatibility gate remain intact.
- The pre-SOAP terminal UI is preserved under `backups/tui-pre-soap` for reference and recovery.

## Compatibility

- Latest compatible vanilla `haiku.rag`; no fork, monkeypatch or private retrieval API.
- Linux x86_64 remains the packaged target.
- Existing 0.5 and 0.6 workspaces upgrade in place without re-indexing the Haiku database.

## Release files

The release publishes the terminal AppImage, native Linux archive, Python daemon wheel, zsync
metadata, installer and SHA-256 manifest. The AppImage remains a small client; the installer or
container provides the isolated Python/Haiku backend.
