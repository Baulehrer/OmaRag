# OmaRag 1.1.0 — models and visual evidence

OmaRag can now recommend models for the current computer. Full manual control remains available in
Expert mode.

## Highlights

- First launch checks RAM, VRAM, and other available resources.
- Ten consumer hardware tiers cover systems from 8 GB of RAM to 64 GB of RAM and 24 GB of VRAM.
- Each tier has a reviewed chat/vision, embedding, and reranker stack.
- **Fast**, **Normal**, and **Quality** control time, context, and source count while remaining
  adaptive to question complexity.
- Preflight shows required downloads, storage, and possible reindexing. Nothing is downloaded or
  changed without confirmation.
- Expert mode still supports full manual model configuration.
- The source panel shows cited pages first, followed by up to four relevant figures or tables.
- Visual assets carry stable links to their page, evidence, and book graph.

## Catalog safety

OmaRag 1.1 includes model catalog `2026.08.1`, dated 14 August 2026. It is not replaced from the
network at launch. OmaRag verifies its checksum and pinned model revisions. A later evaluated
catalog ships only with a later release.

Changing the text embedding model can make an existing library incompatible. OmaRag requires a
separately confirmed full rebuild instead of applying the change partly.

## Visual evidence limit

Page, caption, and graph search can find individual crops. A separate visual vector index exists as
an interface, but 1.1 does not build it automatically for every library. The source-bound fallback
paths remain active without it.

An explicitly selected, locally verified VL model may describe real crops for search and OKF. Its
descriptions are derived hints and are never presented as book evidence.

## Compatibility

- The packaged target is Linux x86-64.
- Existing workspaces and original books are preserved.
- Book structure still uses contents, indexes, glossaries, PDF bookmarks, and a fallback for books
  without usable navigation.
- Haiku RAG and Docling are used only through their verified public APIs.
