# Oracle of Dædalus 0.6.0 — Speed & Trust

This release makes long-book ingestion recoverable, repeat work cheaper and evidence easier to
audit while preserving the public, latest-gated Vanilla Haiku RAG boundary.

## Highlights

- Segment-level crash recovery continues an interrupted PDF instead of starting it again.
- SHA-256 fingerprints identify unchanged content and drive duplicate handling.
- A 5 GiB LRU Docling conversion cache avoids repeated parsing and OCR.
- Per-page classification applies OCR only to scanned ranges; normal text pages stay on the fast
  path and no VL model is run across an entire book.
- A memory governor reserves at least 1.5 GiB (or 15% of RAM) and shrinks conversion segments
  before the system approaches OOM.
- The Retrieval Inspector reports final ranked hits and timing through Haiku's public search API.
- Authenticated PNG evidence previews render the cited page region and work with remote/container
  clients. The TUI falls back to local rendering when necessary.
- SQLite schema v2 upgrades in place; existing libraries and Haiku vector databases remain valid.

## Compatibility

- Latest compatible vanilla `haiku.rag`; no fork, monkeypatch or private retrieval API.
- Linux x86_64 remains the packaged target.
- Existing 0.5 workspaces open without manual migration.

## Measuring your machine

`scripts/benchmark-v06.py <workspace> <pdf> --query "..."` records import time, adaptive
pipeline counts and repeated Retrieval Inspector latency against a running daemon. Results depend
on the selected Ollama models and should be compared with the same PDF, profile and cold/warm cache.
